Calendar feed

Private hotel cancel-deadline reminders, delivered as local calendar alarms.

The feed is disabled: no token is configured, so every feed URL returns 404.

Set the CALENDAR_FEED_TOKEN environment variable (a long random secret) to enable it, then reload this page.

⚠️ Prove it before you rely on it

A missed cancel deadline costs money, and iOS treats alarms on a subscribed calendar differently from ones you own. Validate on your actual iPhone — no hotel needed:

  1. Open Test — Subscribe below and subscribe. On the sheet, keep "Remove Alarms" OFF.
  2. In the Calendar app, pull to refresh; an alert should pop within ~5 minutes — fired from the subscription. That is the real proof.
  3. Only then subscribe to the real feed and trust it. Re-check when the weekly heartbeat alert stops arriving.
